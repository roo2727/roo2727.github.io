# 폰트 파일 안내

## 빛의계승자체 (Sandoll HeirofLight) Regular

- 권리자: 펀플로 · 산돌커뮤니케이션즈 (문의: 컴투스)
- 배포처: https://www.sandollcloud.com/free-font/274/Sandoll-HeirofLight (산돌구름 PC 앱으로 내려받기)
- 라이선스 요약: 개인·기업 무료, 상업적 사용 가능. 웹사이트 사용 가능, 웹사이트 임베딩은 '조건부 허용'.
  권리자 서면 동의 없이 금지: 서체 유료 판매, 서체 수정·편집·재배포, 게임/게임 관련 프로그램 임베딩.

이 저장소에는 폰트 파일을 넣지 않았습니다 (재배포 조항 때문).
웹에서 쓰려면 권리자에게 웹폰트 사용 조건을 확인한 뒤, 아래 이름으로 이 폴더에 넣으면 자동으로 적용됩니다.

- `HeirofLight-Regular.woff2` (권장) 또는 `HeirofLight-Regular.otf`

파일이 없어도 PC 에 폰트가 설치되어 있으면 그 폰트로 보이고, 둘 다 없으면 Gowun Batang 으로 표시됩니다.
연결 코드는 `css/base.css` 의 `@font-face` 에 있습니다.

## Pretendard / Cinzel

- Cinzel: SIL OFL 1.1, Google Fonts 로 불러옴
